UI / UX 方向の比較

仕様は共通です。見た目と空気感だけが違います。各カードから実寸のモックを開き、 タイトル → 難易度 → プレイ → 結果 → 分析 を行き来して比べてください。

PATTERN A

ワークスペースポップ

いちばん Slack に近い骨格。明るいサイドバーと丸いアバター、年収はヘッダーのピル。日常業務っぽさとポップさを両立。

  • チャット製品の再現度が高い
  • 装飾は控えめ、色はアバターとバッジで出す
  • 長時間プレイしても疲れにくい想定
A を開く
PATTERN B

年収アーケード

チャットは残しつつ、年収・タイマー・コンボをゲームHUDとして前面に出す。送信の快感とスコアの伸びを最優先。

  • 寿司打的な「稼いでいる感」が強い
  • ネオン寄りのビビッド配色
  • 入力欄が司令室コンソール
B を開く
PATTERN C

スタートアップステッカー

雑誌の特集のような大きな文字と、LGTM / hotfix 風ステッカー。ホームがカードの弁当レイアウト。世界観のネタが強い。

  • カタカナ好き主人公の世界観が前面
  • パステル＋原色のシール感
  • 分析画面もダッシュボードっぽい
C を開く
選ぶときの観点の例: 「毎日打ちたい見た目か」「年収が主スコアだと一瞬で分かるか」「返信文が読みやすいか」「Slack風で迷わないか」。 組み合わせ（例: 骨格はA、プレイ中HUDだけB）でも構いません。
