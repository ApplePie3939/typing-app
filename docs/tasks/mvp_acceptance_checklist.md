# MVP Acceptance Checklist

仕様: `docs/specs/mvp.md`  
実装完了の宣言前にすべて確認する。

## 環境・運用

- [ ] リポジトリは Linux ファイルシステム上（`/mnt/c` 配下ではない）
- [ ] `direnv allow` 後に Nix 開発シェルが有効になる
- [ ] GitHub 公開リポジトリ `ApplePie3939/typing-app` がある
- [ ] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [ ] `just check` が lint・typecheck・test・build を実行して成功する
- [ ] D1 の schema 変更は migration として Git 管理されている
- [ ] ローカル D1 と本番 D1 が分離されている
- [ ] MVP 問題データの投入手段（just 経由）がある
- [ ] React と Hono が 1 つの Worker にまとまっている
- [ ] Wrangler で Cloudflare Workers にデプロイ済み（GitHub Actions なし）

## プレイ

- [ ] タイトル → 難易度 → プレイ → 結果の導線がある
- [ ] タイトルから分析へ直接入れる
- [ ] 遊び方の短い説明がある
- [ ] 3 難易度（初級 / 中級 / 上級）で 60 秒プレイが最後までできる
- [ ] 最初の有効入力でタイマーが始まる
- [ ] 返信は日本語表示、入力はローマ字である
- [ ] 正しいキーのみ進み、ミスでは位置が戻らずミス数が増える
- [ ] `し` など一般的なローマ字揺れを受け入れる
- [ ] 全文一致で自動送信され、次の通に進む
- [ ] 時間切れで入力途中の通は年収に入らない
- [ ] プレイ中のキーイベントを都度 API に送っていない

## スコア・結果

- [ ] 送信のたびにゲーム内年収が増える（プレイ中から見える）
- [ ] 結果に合計年収、入力速度、正確性、ミス数、最大連続入力数、送信通数が出る
- [ ] もう一度（同難易度）・難易度変更・分析・タイトルへ戻れる

## 分析・識別

- [ ] 初回アクセスで匿名 ID がブラウザに保存される
- [ ] 同じブラウザの履歴が分析に反映される
- [ ] 複数プレイ後、苦手キー / 指 / 2 キー遷移が見られる
- [ ] データ不足時の空状態がある
- [ ] ログイン機能がない
- [ ] 個人情報を保存していない

## コンテンツ・UI

- [ ] 各難易度 15 通以上
- [ ] 世界観（カオスワークス、カタカナ、1 通 1 ボケ）とジャンル混在を満たす
- [ ] URL 級の高負荷題材がない
- [ ] Slack 風で、白ベースかつカラフル（スタートアップステッカー）
- [ ] デスクトップ想定で入力対象と現在位置が分かる
- [ ] ミスは入力欄の短い反応に留め、画面全体を赤くしない

## 品質

- [ ] ローマ字判定・年収計算・統計集計のテストがある
- [ ] `just check` 成功
- [ ] ローカルで一通りプレイできる
