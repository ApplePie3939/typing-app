# MVP Acceptance Checklist

仕様: `docs/specs/mvp.md`  
実装完了の宣言前にすべて確認する。

## 環境・運用

- [x] リポジトリは Linux ファイルシステム上（`/mnt/c` 配下ではない）
- [x] `direnv allow` 後に Nix 開発シェルが有効になる（ユーザー側で `direnv allow` が必要）
- [x] GitHub 公開リポジトリ `ApplePie3939/typing-app` がある
- [x] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [x] `just check` が lint・typecheck・test・build を実行して成功する
- [x] D1 の schema 変更は migration として Git 管理されている
- [x] ローカル D1 と本番 D1 が分離されている
- [x] MVP 問題データの投入手段（just 経由）がある
- [x] React と Hono が 1 つの Worker にまとまっている
- [x] Wrangler で Cloudflare Workers にデプロイ済み（GitHub Actions なし）

## プレイ

- [x] タイトル → 難易度 → プレイ → 結果の導線がある
- [x] タイトルから分析へ直接入れる
- [x] 遊び方の短い説明がある
- [x] 3 難易度（初級 / 中級 / 上級）で 60 秒プレイが最後までできる
- [x] 最初の有効入力でタイマーが始まる
- [x] 返信は日本語表示、入力はローマ字である
- [x] 正しいキーのみ進み、ミスでは位置が戻らずミス数が増える
- [x] `し` など一般的なローマ字揺れを受け入れる
- [x] 全文一致で自動送信され、次の通に進む
- [x] 時間切れで入力途中の通は年収に入らない
- [x] プレイ中のキーイベントを都度 API に送っていない

## スコア・結果

- [x] 送信のたびにゲーム内年収が増える（プレイ中から見える）
- [x] 結果に合計年収、入力速度、正確性、ミス数、最大連続入力数、送信通数が出る
- [x] もう一度（同難易度）・難易度変更・分析・タイトルへ戻れる

## 分析・識別

- [x] 初回アクセスで匿名 ID がブラウザに保存される
- [x] 同じブラウザの履歴が分析に反映される
- [x] 複数プレイ後、苦手キー / 指 / 2 キー遷移が見られる
- [x] データ不足時の空状態がある
- [x] ログイン機能がない
- [x] 個人情報を保存していない

## コンテンツ・UI

- [x] 各難易度 15 通以上
- [x] 世界観（カオスワークス、カタカナ、1 通 1 ボケ）とジャンル混在を満たす
- [x] URL 級の高負荷題材がない
- [x] Slack 風で、白ベースかつカラフル（スタートアップステッカー）
- [x] デスクトップ想定で入力対象と現在位置が分かる
- [x] ミスは入力欄の短い反応に留め、画面全体を赤くしない

## 品質

- [x] ローマ字判定・年収計算・統計集計のテストがある
- [x] `just check` 成功
- [x] ローカルで一通りプレイできる（API と画面配信を確認。実キーボード操作はローカル `just dev` で確認）
