# フルスタ打 MVP 仕様

Web ブラウザで遊ぶ、IT エンジニアのチャット返信を模したタイピングゲームの現行 MVP 仕様です。  
元資料: `docs/MVP仕様書.md`（プロダクト仕様の原本）。本ファイルは実装に必要な決定を含む現行仕様です。

**正式名称:** フルスタ打  
**UI:** パターン C「スタートアップステッカー」（`mockups/pattern-c.html`）

---

## プロダクト概要

相手から届いた社内チャットに対し、用意された返信文をローマ字入力で打ち切る。

- Slack 風のチャット画面
- 舞台は今どきの IT 企業。トラブル多め。カタカナ語とボケが好きなフルスタック主人公
- メインスコアはゲーム内年収

プレイヤーは文章を考えず、提示された返信を正確かつ速く入力する。

---

## 技術構成（実装）

単一リポジトリ・単一 Cloudflare Worker。

- フロント: React + TypeScript（Vite+）
- API: Hono（同一 Worker）
- データ: Cloudflare D1（ローカル D1 と本番 D1 を分離）
- デプロイ: Wrangler（GitHub Actions なし）
- 開発環境: WSL2 + Nix flake + direnv + just。JS ツールチェーンは Vite+（`vp`）に任せる

## ゲームフロー

```
タイトル → 難易度選択 → プレイ（60秒） → 結果
タイトル / 結果から分析へ
```

- 制限時間: 全難易度 60 秒
- 最初の有効入力でタイマー開始
- 1 通打ち切りで自動送信 → 年収加算 → 次の通
- 時間切れで終了。途中の通は不成立（その通の年収は 0）
- 正しいキーのみ進行。ミスはカウントして位置は進まない。バックスペースで戻さない
- ローマ字の揺れ（し = `si` / `shi` など）を許容する
- キーイベントはプレイ中ブラウザ内で集計し、終了時にまとめて保存する

---

## 画面

- **タイトル:** ゲーム名、キャッチ、スタート、分析、遊び方
- **難易度:** 初級 / 中級 / 上級のカード（肩書き付き）
- **プレイ:** Slack 風（装飾のサイドバー、チャンネル、履歴、入力欄）。年収と残り時間を常時表示
- **結果:** 合計年収、入力速度、正確性、ミス数、最大連続入力数、送信通数
- **分析:** 当該ブラウザの累計。苦手キー / 指 / 2 キー遷移。空状態あり

## 難易度

| ID | 表示 | 肩書き | 目安文字数 |
| --- | --- | --- | --- |
| beginner | 初級 | 新米エンジニア | 15〜40 字 |
| intermediate | 中級 | 慣れてきたエンジニア | 40〜80 字 |
| advanced | 上級 | つよつよエンジニア | 80〜140 字 |

各難易度 15 通以上。出題はシャッフルし、同じ通の連打を避ける。

## スコア

```
獲得額 = 難易度の基準額 × 速度倍率 × 正確性倍率
```

端数は百円単位に丸める。

| 難易度 | 基準額 | 目標速度（正しいキー/分） |
| --- | --- | --- |
| 初級 | 120,000 | 200 |
| 中級 | 220,000 | 280 |
| 上級 | 350,000 | 360 |

- 速度倍率: `(その通の正しいキー/分) / 目標速度` を 0.5〜2.0 にクランプ
- 正確性: 正しいキー / （正しいキー + ミス）
- 正確性倍率: `max(0, (正確性 - 0.5) × 2)`（100% で 1.0、90% で 0.8、50% 未満で 0）

プレイ全体の入力速度は 1 分あたりの正しいキー数。正確性は小数 1 桁パーセント。

## データ

D1 にタイピング問題とプレイ結果を保存する。問題は最低限、相手メッセージ・返信文・返信の読み・難易度を持つ。

識別子は初回アクセス時に匿名 UUID をブラウザへ保存する。ログインなし。氏名・メール等の個人情報は保存しない。

分析用のキー / 指 / バイグラム統計はプレイ結果に JSON で保存し、取得時に累計する。

---

## API（MVP）

- `GET /api/prompts?difficulty=` … 問題一覧
- `POST /api/plays` … 1 プレイ分の結果を保存
- `GET /api/stats?playerId=` … 当該匿名 ID の累計分析

プレイ中のキー入力は API に送らない。
